# A Cozinha do Rei — demo NOVA7

Apresentação exclusiva para Paulo Margarido, com os três reels do restaurante.

## Conteúdo

- `site/p/paulo-margarido-7f2c91/`: página e todos os recursos necessários.
- `site/index.html`: página neutra, sem ligação para a apresentação.
- `.github/workflows/pages.yml`: publicação automática através do GitHub Pages.
- `FONTES.md`: origem do conteúdo e referências visuais.

## Publicação

1. Criar um repositório dedicado, sugerido `cozinha-do-rei-demo`.
2. Enviar o conteúdo deste pacote por Git para a branch `main`, incluindo a pasta `.github`. Os vídeos maiores excedem o limite de envio pela interface web; não carregar o ZIP como um único ficheiro no repositório.
3. Em Settings → Pages, escolher GitHub Actions como origem. Executar o workflow se o primeiro envio ocorreu antes desta configuração.
4. Aguardar o workflow terminar com sucesso e verificar a página e os três vídeos.

Endereço publicado e verificado em 17/10/2026:
`https://pkalysto.github.io/cozinha-do-rei-demo/p/paulo-margarido-7f2c91/`

A demo tem noindex e está fora da navegação. Não tem palavra-passe: o endereço e os ficheiros de um repositório público podem ser consultados por outras pessoas.

Workflow adaptado do exemplo oficial: https://github.com/actions/starter-workflows/blob/main/pages/static.yml
